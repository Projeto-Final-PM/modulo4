# Kafka Producer 

### **KafkaTopicConfig.java**
Configura o tópico Kafka usado pelo produtor. Define nome, quantidade de partições e garante que o tópico exista no cluster.

### **MessageEventProducer.java**
Classe responsável por enviar mensagens ao Kafka.

### **KafkaProducerApplication.java**
Classe principal da aplicação. Inicia o Spring Boot e carrega as configurações do produtor.

### **application.yml**
Arquivo de configuração do Kafka.
